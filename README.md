# CELLGUARD

## AI-Powered EV Battery Manufacturing Quality Intelligence

**SEE → EXPLAIN → PREDICT → PREVENT**

CELLGUARD is an AI-powered quality intelligence prototype for EV
battery cell/tab weld inspection.

It combines computer vision, manufacturing process analysis,
root-cause estimation, future defect-risk prediction, and
preventive action recommendations.

## Data Transparency

CELLGUARD uses publicly available visual inspection data and a
realistic synthetic manufacturing-process dataset to demonstrate
the complete quality-intelligence pipeline.

The synthetic manufacturing-process data is not real factory data.

## Technical Honesty

The system estimates future defect risk and recommends preventive
action.

It does not guarantee failure prevention.

The root-cause module identifies the most probable contributing cause
based on observed process patterns. It does not prove the physical
root cause.
