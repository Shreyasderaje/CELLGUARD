# CELLGUARD

## AI-Powered EV Battery Manufacturing Quality Intelligence

CELLGUARD is an AI-based quality intelligence prototype for EV battery
cell and battery tab/weld inspection.

### Core Pipeline

SEE → EXPLAIN → PREDICT → PREVENT

### Main Modules

- Computer Vision Defect Detection
- Defect Severity Analysis
- Root Cause Analysis
- Future Defect Risk Prediction
- Quality Time Machine
- Factory Risk Board
- Corrective Action Recommendation
- What-if Process Simulation

### Track

Singularity 2026 — Track 3
AI-Based Automotive Component Quality Inspection

### Technical Honesty

The visual inspection component will use suitable publicly available
inspection data where possible. Manufacturing process data used in the
prototype may be synthetic and will be clearly labelled as such.
